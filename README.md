# AI Brochure Generator

AI Brochure Generator is an AI-powered web application that automatically creates professional company brochures from website content using Google Gemini AI. The application leverages web scraping, content analysis, and generative AI to transform company website information into structured, visually appealing marketing brochures through an interactive Streamlit interface.

This project showcases the integration of modern AI technologies, prompt engineering, and Python-based web application development to automate business content generation workflows.
